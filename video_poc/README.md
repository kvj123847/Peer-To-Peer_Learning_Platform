# Video Provider POC

## Objective

Evaluate a real-time video provider for the peer-learning platform.

## Providers

- Agora
- Twilio Video
- Stream Video

## POC Tests

- 1-to-1 video call
- Group video call
- Camera and microphone
- Mute/unmute
- Camera on/off
- Participant join/leave
- Network interruption
- Reconnection
- Mobile SDK quality
- Recording capabilities
- Moderation/safety capabilities
- Pricing
